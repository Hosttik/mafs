# Minecraft AI Film Studio — проектирование

Дата: **26 октября 2026**, Europe/Bratislava. Статус: **предложение для согласования; реализация не начата**.

Цель первого MVP: одна оригинальная, понятная без речи история на 60–120 секунд, снятая внутри Minecraft Java, с автоматическим отчётом и ограниченным исправлением неудачных кадров.

Рекомендуемый путь: независимое Python-приложение для производства и анализа + небольшой Java-адаптер к зафиксированной версии Minecraft/Fabric/BBS FS. Сценарий проходит через смысловые сцены, режиссёрский план и проверяемую постановку до компиляции в команды движка.

Сейчас выполнено исследование исходников и документации. Minecraft не запускался, референсные MP4 не предоставлены и не анализировались, платные API-вызовы не выполнялись. Старый репозиторий читался через GitHub и не изменялся. Ни один документ не является разрешением расходовать предложенный бюджет.

После согласования архитектуры следующий этап — ограниченная техническая проверка выразительности и повторяемости съёмки. Масштабирование до 10–15 минут зависит от качества короткого пилота.
