# Minecraft AI Film Studio — проектирование

Дата: **26 октября 2026**, Europe/Bratislava. Статус: **предложение для согласования; реализация не начата**.

Главный подход — **Reference-Driven Iterative Film Production**: референсы служат постоянной основой анализа и сравнительной оценки собственных фильмов, а подтверждённые результаты исправлений пополняют знания студии. Дообучение весов моделей для MVP не предполагается.

Главный вопрос MVP: **можем ли мы систематически улучшать качество собственного Minecraft-фильма, сравнивая его с сильным референсом, а не только генерировать и оценивать ролики?**

Первый исследовательский цикл: один референс Alan Becker для сюжетной структуры, один релевантный референс Ethobot для постановки, законченная адаптация на **30–60 секунд** внутри Minecraft, сравнение, исправление хотя бы одного существенного естественного недостатка, повторное сравнение и зрительская проверка «до/после». Ручная постановочная доработка допустима и учитывается явно. Полный производственный конвейер до проверки этого цикла не строится.

Рекомендуемый путь: независимое Python-приложение для производства и анализа + небольшой Java-адаптер к зафиксированной версии Minecraft/Fabric/BBS FS. Сценарий проходит через смысловые сцены, режиссёрский план и проверяемую постановку до компиляции в команды движка.

Сейчас выполнено исследование исходников и документации. Minecraft не запускался, референсные MP4 не предоставлены и не анализировались, платные API-вызовы не выполнялись. Старый репозиторий читался через GitHub и не изменялся. Ни один документ не является разрешением расходовать предложенный бюджет.

Режимы: **Reference Reconstruction Mode** — внутренняя исследовательская адаптация заданной драматургии; **Original Generation Mode** — оригинальные истории с функциональным сравнением с эталонами и собственной историей производств. Исследовательская реконструкция не является публичным оригинальным выпуском.

После успешного сравнительного пилота: оригинальные истории 60–120 секунд → 3–5 минут → позднее 10–15 минут. Один успешный цикл даёт локальное свидетельство; систематичность требует повторения на других историях. Проверка документации и её push не означают разрешения запускать производство или платные API.
